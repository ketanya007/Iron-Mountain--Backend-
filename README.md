# Expense Manager

A full-stack Expense Manager application designed to split bills, calculate balances, and settle debts efficiently among groups.

## Project Structure
- `/backend`: Node.js, Express, MongoDB REST API.
- `/frontend`: React UI (Pending implementation).

## Tech Stack
- **Backend:** Node.js, Express.js, MongoDB, Mongoose
- **Frontend:** React.js (To be built)

## Quick Start (Backend)
1. `cd backend`
2. `npm install`
3. Set `MONGO_URI` and `PORT` in your `.env`
4. `npm run dev`
